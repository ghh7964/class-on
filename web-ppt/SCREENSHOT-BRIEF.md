# CLASS:ON 웹 PPT 새 캡처 브리프

본편은 새 캡처가 없어도 작동합니다. 아래 세 장을 준비하면 향후 시연 진입 슬라이드나 발표 보고서에 선택적으로 사용할 수 있습니다.

## 공통 조건

- 실제 `web-demo/dist/?mode=present`를 사용합니다.
- 16:9, 권장 1920×1080 또는 1600×900입니다.
- 브라우저 탭·주소창·바탕화면은 제외하고 앱 화면만 캡처합니다.
- 화면 전체의 큰 여백보다 발표에서 읽을 근거가 크게 보이도록 크롭합니다.
- 김민준은 반드시 `가상학생` 표기가 함께 보이게 합니다.
- 개인정보·장애·건강·상담·가정정보를 새로 만들지 않습니다.

## 캡처 A · 노동에서 선택까지

목적: 공개채용을 통해 번 ON이 신청곡·공동프로젝트 선택으로 이어졌음을 한 화면에서 확인합니다.

- 데모 상태를 초기화한 뒤 `웹 게시 작업` 지원과 `다음 상태`를 완료합니다.
- 지갑·거래내역에서 임금, 근로세, 세후입금, 신청곡 `-2 ON`, 공동프로젝트 `-3 ON`이 읽혀야 합니다.
- 우측이나 하단의 비어 있는 영역은 최소화하고 거래내역을 중심으로 크롭합니다.
- 파일명 제안: `09-wallet-choice-clean.png`

## 캡처 B · 제도 디버그 1.1

목적: 문제를 발견한 뒤 수정안을 4주 시험하고 다음 결산으로 넘기는 흐름을 확인합니다.

- `처음 하는 학생도 함께 뽑기`를 선택한 1.1 결과 상태를 캡처합니다.
- `1.1`, 시험기간 또는 다음 결산, 기본권·안전은 시험대상이 아니라는 경계가 읽혀야 합니다.
- 선택 전 화면보다 결과 화면을 우선하고, 큰 빈 여백과 브라우저 UI는 제외합니다.
- 파일명 제안: `10-debug-1-1-clean.png`

## 캡처 C · 권리 우선 자리배치

목적: 자리 자체를 판매하지 않고 필요한 자리를 먼저 보장한 뒤 선택순서와 희망구역을 다룬다는 점을 보여줍니다.

- `CLASS:ON → 순환 자리배치` 페이지를 사용합니다.
- `필요한 자리는 먼저 보장합니다`, `선택순서 3장`, `좌석 자체를 사는 것이 아님`, `1·2순위 희망구역`이 함께 읽히게 캡처합니다.
- 입찰액이나 특정 구역 선택을 강조하기보다 권리 우선 절차가 먼저 보이게 합니다.
- 파일명 제안: `11-seating-rights-first-clean.png`

## 사용 위치

- 캡처 A: 본편 s5의 라이브 시연 대체 또는 Q&A q10의 구현범위 근거
- 캡처 B: 본편 s7의 라이브 시연 대체 또는 Q&A q10의 구현범위 근거
- 캡처 C: 본편 s5 자리배치 설명의 실패 대비 또는 Q&A q5의 절차 근거

캡처를 추가해도 기존 `01`~`08` 파일은 삭제하지 않습니다. 백업 버튼 경로를 바꾸기 전 실제 화면과 문서 수치를 다시 대조합니다.

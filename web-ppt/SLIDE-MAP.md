## 이미지 사용

새 외부 사진을 사용하지 않았습니다. 고1의 서로 다른 출발점은 식별 가능한 학생 사진 대신 CSS 도식으로 표현했습니다. 현재 본편에는 캡처 이미지를 직접 배치하지 않고 라이브 시연 진입 구조만 둡니다. `web-demo/screenshots/`의 01~07은 실패 시 전체화면 백업으로 엽니다. `08-accessibility-job.png`는 파일만 보존하며 Q&A 참고자료에는 개인정보 경계와 운영원칙을 텍스트로 정리했습니다. 새 캡처가 준비되면 `SCREENSHOT-BRIEF.md` 기준으로 교체합니다.

## 문서 충돌 기록

- `professor-qa-bank.md`의 P-03에는 금고 경보가 `204/112`로 적혀 있으나, 문서 우선순위상 상위인 `economic-model.md`와 `system-spec.md`의 현행값은 `156/88`입니다. q4는 `156/88`을 사용했습니다.
- 최신 시나리오는 제도 디버그 수정안을 `견습 경로 추가`라고 설명하고 실제 데모는 `처음 하는 학생도 함께 뽑기`로 표시합니다. 본편 s7은 실제 데모 문구를 사용하고 노트에서 같은 의미임을 설명합니다.
- `web-demo/README.md`의 지갑 설명에는 최종 19.8 ON이 적혀 있으나 최신 `04-wallet.png` 화면 상단에는 23.8 ON이 보입니다. PPT 본편은 금액을 핵심 주장으로 사용하지 않고 실제 화면을 그대로 보여줍니다. 발표 전 데모 초기화 뒤 거래내역 합계가 문서와 일치하는지 다시 확인해야 합니다.

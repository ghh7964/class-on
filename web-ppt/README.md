# CLASS:ON 16:9 웹 PPT

일반계 고1 학급경영계획을 약 6분 30초에 발표하기 위한 정적 HTML·CSS·JavaScript 슬라이드입니다. 정식 `.pptx`나 학교서비스가 아니며, 별도 빌드와 패키지 설치가 없습니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 4173
```

- PPT: `http://127.0.0.1:4173/web-ppt/`
- 실제 웹 데모: `http://127.0.0.1:4173/web-demo/dist/?mode=present`

로컬 파일을 직접 열 수도 있지만 새 탭 재사용과 상대경로 이미지 로딩을 위해 로컬 서버 실행을 권장합니다. Pretendard CDN을 불러오지 못하면 Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic 순으로 대체합니다.

## 발표 전 준비 순서

1. 위 로컬 서버를 켭니다.
2. PPT 주소를 열고 `시연 1 열기`를 한 번 눌러 브라우저 팝업을 허용합니다.
3. 데모 탭에서 `상태 초기화`를 누른 뒤 PPT 탭으로 돌아옵니다.
4. 시연 1에서는 `일·공개채용 → 웹 게시 작업 → 지원 → 다음 상태 → 지갑·거래내역 → 청소시간 신청곡 → 순환 자리배치`를 연속 조작합니다. 자리배치에서는 필요좌석 선보장을 먼저 설명하고, `학급 접근성 지원` 공고는 본편에서 열지 않습니다.
5. 시연 2에서는 `시연 2 시작 → 처음 하는 학생도 함께 뽑기 → 이 방법으로 4주 시험하기`를 조작합니다.
6. 동일 기기에서 전체 동선을 3회 반복해 새로고침, 중복클릭, 초기화, 1.0→1.1을 확인합니다.

`시연 1 열기`와 `시연 2 열기`는 같은 이름의 브라우저 탭을 재사용합니다. 팝업이 차단되면 시연 1 슬라이드의 `일반 링크`를 사용합니다. 시연이 끝나면 `Cmd+Tab` 또는 브라우저 탭 전환으로 PPT에 복귀합니다.

## GitHub Pages 배포

PPT와 데모가 같은 Pages 프로젝트에 있으면 기본 상대경로가 그대로 작동합니다.

- PPT: `https://사용자명.github.io/저장소/web-ppt/`
- 데모: `https://사용자명.github.io/저장소/web-demo/dist/?mode=present`

서로 다른 저장소나 도메인에 배포한다면 `index.html`의 아래 메타 태그 `content`만 실제 데모 URL로 바꿉니다. 버튼과 일반 링크가 같은 값을 사용합니다.

```html
<meta name="class-on-demo-url" content="https://사용자명.github.io/데모저장소/?mode=present" />
```

배포 후 팝업 허용, 동일 탭 재사용, `#debug` 진입, PPT 탭 복귀를 실제 Pages URL에서 다시 확인해야 합니다.

## 조작

- 이전/다음: `←`, `→`, `PageUp`, `PageDown`, `Space`
- 본편 처음/마지막: `Home`, `End`
- 전체화면: `F`
- 오버레이 닫기: `Esc`
- 터치: 화면을 좌우로 스와이프

URL hash로 `#s1`~`#s9`, `#q1`~`#q10`과 분리된 접근성 자료 `#q6b`에 직접 접근할 수 있고 새로고침 뒤에도 현재 슬라이드가 복구됩니다. 본편 마지막 `s9`에서는 다음 키를 눌러도 Q&A로 자동 이동하지 않습니다. 결론의 `Q&A` 버튼으로 진입합니다.
